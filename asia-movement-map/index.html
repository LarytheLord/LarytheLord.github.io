Every organisation written on a board, merged across spellings. See what the boards say about it, its public profile, who attended, and which gaps elsewhere its work could answer. If something about your organisation is wrong, use the correction link on its card.

Each board was filled in separately by the people at that region's table. Read side by side, a few patterns show up that no single board shows.

Theme matrix

Where the work is, and where the gaps are

Every note is coded to one or more themes. For each region, the left number counts Current Work notes and the right number counts notes from the three gap columns. Select a number to read the notes behind it. On a phone, scroll the table sideways.

Comparison

Bottlenecks named in more than one region

The same constraint, in each region's own words. A blank means nobody at that table wrote it down, not that it is not a problem there.

Outside evidence

What published sources say about the themes

Short, sourced context so readers can judge the size of each gap. Every line links to its source.

Source

The three boards, note by note

A transcription of every note, in the board's own four columns, kept as written. Each note was read three times independently from full-resolution photos. A dashed outline marks a note with words that are covered or too faint to read with confidence.
